  # Chat-Box

  A self-contained, two-pane chat UI demo in a single HTML file. Two side-by-side
  windows (AHMAD and ARHAM) let you type messages into either pane and watch them
  appear as styled, timestamped bubbles — like a WhatsApp conversation viewed from
  both sides.

  ## Features

  - Two independent chat panes, each with a profile header and message input
  - Messages appear as bubbles with a `HH:MM AM/PM` timestamp
  - Press **Enter** or click send to post a message
  - Sender-colored bubbles (green / white) that align left or right by sender
  - Pure vanilla HTML/CSS/JavaScript — no libraries, no backend

  Notes

  This is a UI demo: messages are not saved or sent anywhere — they live only in
  the page until you reload. Requires the accompanying image assets
  (dp1.jpeg, dp2.jpeg, send.jpeg, bg1.jpeg, bg2.jpg) to be present.
